# 关联以运行时发现为主，配置文件降级为可选增强

接入 MacLauncher 不再要求项目准备 `maclauncher.json`：应用经 SDK 连接启动器的 Unix socket 并自报项目名、服务声明与可选拉起入口，启动器把未知项目放入待批准，用户在管理窗口一次性批准即建立运行时绑定；配置文件路径保留，为需要稳定服务清单、完整拉起命令与配置刷新的项目提供可选增强。

选择 socket 自发现 + 一次性批准（来源：运行时发现地图 #45，方案 A）是因为成品应用与临时工程脚本都不应被迫维护配置文件，而无条件的自动批准会把统一入口交给任何能连上 socket 的本地进程。五个决策点：①未自报入口也允许批准（仅观察与回收，启动器不能拉起）；②忽略列表按项目标识持久化，设置页可恢复；③运行时绑定与配置绑定撞同一项目标识时走既有身份冲突弹窗（迁移原绑定会把绑定转为配置绑定）；④不做自动批准开关；⑤入口自报允许完整启动命令（args、工作目录）。
