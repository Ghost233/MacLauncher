## 对 MacLauncher 规划的影响

独立应用隐藏自己的入口，不能等同于退出该应用；若退出仍会结束受管服务，菜单栏接管本身不会满足分离运行。MacLauncher 的 SDK 需要另行明确入口接管/归还与服务生命周期的职责，而后由 JevManager 自己选择如何接入。

项目/服务的稳定标识、现有运行发现、控制能力、真实运行与就绪状态、日志来源和恢复读取均是尚待定义的接入契约。此处不为 JevManager 增加这些接口，也不把它们当作已可调用的能力。

本快照用于提供规划上下文；具体协议、托管方案与验收要求应在对应决策工单中确定。
