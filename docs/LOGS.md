# 日志查看

日志面板展示**应用报告的**最近日志批次。启动器不捕获业务输出、不写日志文件、
不合并历史记录；应用没有日志能力时面板显示不可用说明。

## 打开与读取

- 在服务行点击「日志」打开面板；打开期间每 2 秒重新查询一次，关闭后立即停止
  （后台不再读取）。
- 每次查询默认取最近 200 条；`limit` 越界时按协议收敛到 1–500。
- 每批日志**整体替换**上一批，绝不拼接、追加或本地造数。

## 批次契约

- 条目按应用报告的旧→新顺序展示，最多 `limit` 条。
- `timestamp` 缺失时显示「无原始时间」；`stream` 为未知时标「未知」，绝不把
  stderr 猜测为 stdout。
- 批次未带实例标识时标「未提供实例范围」；`truncated` 为真时提示批次被截断。
- 查询失败时保留上一批内容并明显标记「旧内容」及失败原因；空批次与查询失败是
  两种不同显示状态。

## 不可用与失败

- 应用未注册 `logs` 能力 → 显示「应用未提供日志能力」，不会向应用发送请求。
- 超时/断连 → 显示「结果未知」或连接状态，保留上批旧内容。
